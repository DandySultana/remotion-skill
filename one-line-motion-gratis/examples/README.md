# Contoh per preset gaya

Kode 10 video contoh, satu file per preset (`demos/dNN-<preset>.tsx`), memakai kerangka bersama `lib/index.tsx` (font, helper gerak, grain, subtitle, transisi, mixing VO/musik/SFX).

Cara pakai saat membuat video baru:
1. Buka file contoh untuk preset yang dipilih.
2. Ambil palet `C`, latar, dan komponen ilustrasinya sebagai titik awal.
3. Ganti isi adegan sesuai naskah; pertahankan prinsip gerak dan tata letaknya (teks utama di luar pita subtitle 70–80% tinggi layar).

`config.ts` berisi naskah tiap contoh. `d01-kartun.tsx` memakai adegan template di `../template/src/scenes`.
